# Reflexión Final: Conclusión y Aprendizajes

## Conclusión
El desarrollo de este tablero de visualización permitió comprender de forma práctica la importancia del análisis de datos para la gestión empresarial. 
A través de las métricas y visualizaciones generadas, fue posible observar de manera clara cómo las ventas varían según la región, los productos más demandados 
y el comportamiento de los clientes en el tiempo.  
El proyecto demuestra que una correcta presentación de los datos facilita la toma de decisiones estratégicas y la identificación de oportunidades de mejora dentro del negocio.

## Aprendizajes
Durante la realización de este taller se adquirieron conocimientos clave en el uso de herramientas de análisis con Python, 
especialmente en las librerías Plotly, Matplotlib y Seaborn.  
Entre los aprendizajes más importantes se destacan:
- La correcta estructuración de un dataset para análisis visual.  
- La creación de indicadores clave (KPIs) que resumen el rendimiento general del negocio.  
- La aplicación de principios de diseño para lograr visualizaciones claras, comprensibles e interactivas.  
- El uso de Python como alternativa efectiva frente a herramientas como Power BI para construir tableros personalizados.

Además, se fortaleció la comprensión del valor de los datos como recurso estratégico, 
ya que su análisis permite anticipar comportamientos, detectar tendencias y mejorar la toma de decisiones.  
El ejercicio reafirma que visualizar los datos es una forma de contar historias con propósito, ayudando a comunicar resultados de manera efectiva y visualmente atractiva.
